# Project Rules for reels-creator

## Git & File Formatting Guidelines

1. **User Review & Editor Formatting Before Committing**:
   - Do **not** commit or push changes immediately after creating or editing files.
   - Always allow the user to review the files in their editor first, so that automatic editor formatting (such as trailing newlines, indentation, and linting) can be applied naturally before staging.
   - Wait for explicit user review and confirmation before running `git add`, `git commit`, or `git push`.
